# Wasteland Workshop Studio

An original, unofficial, cross-generation Fallout mod-authoring workbench, beginning with editable Fallout 1 and Fallout 2 `.msg` dialogue resources.

The first implementation is being developed in a pull request. The browser application is deliberately sandboxed and does **not** inspect, alter, or install game files. Game formats, 3D game support, and desktop integration will be introduced through separate, validated adapters.

This is an independent community project and is not affiliated with or endorsed by Bethesda Softworks, Bethesda Game Studios, or the owners of the Fallout franchise.
